# Система заказов для заведения общественного питания

Программный модуль представляет из себя систему для создания, оплаты и приготовления заказов от клиентов. Система ведет учет только одного ресторана и используется независимо от других ресторанов сети.

Система состоит из следующих компонентов:

1. Веб-API (ASP.NET Core Web Api). Application Program Interface для прямого взаимодействия с базой данных. Планируется опубликовать API в публичный доступ.  Для создания базы данных будет использоваться Entity Framework Migration.
2. Мобильное приложение (MAUI). Использует технологию MAUI с подключением к API.
3. Веб-сайт (React). Использует технологию React с подключением к API. Также веб-сайт будет использоваться на терминалах самообслуживания.
4. Админ-панель (WPF-приложение). В админ-панели будет отображение всех нужных аналитик и данных для директора и менеджеров ресторана.
